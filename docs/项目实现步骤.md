### 步骤 2: 数据库模块 (`database.py`)

**核心逻辑：**

- 使用 SQLAlchemy 连接 SQLite
- 创建 `orders` 表（字段见需求文档第六章）
- 建立 `(name, address, phone)` 组合索引和 `expire_at` 索引

**关键代码结构：**

```python
from sqlalchemy import create_engine, Column, Integer, String, DateTime, Index
from sqlalchemy.ext.declarative import declarative_base
from sqlalchemy.orm import sessionmaker
from datetime import datetime

DATABASE_URL = "sqlite:///./data/orders.db"
engine = create_engine(DATABASE_URL, connect_args={"check_same_thread": False})
SessionLocal = sessionmaker(autocommit=False, autoflush=False, bind=engine)
Base = declarative_base()

class Order(Base):
    __tablename__ = "orders"
    id = Column(Integer, primary_key=True, autoincrement=True)
    name = Column(String, nullable=False)
    address = Column(String, nullable=False)
    phone = Column(String, nullable=False)
    batch_id = Column(String, nullable=True)
    created_at = Column(DateTime, default=datetime.utcnow)
    expire_at = Column(DateTime, nullable=False)

    __table_args__ = (
        Index('idx_name_addr_phone', 'name', 'address', 'phone'),
        Index('idx_expire_at', 'expire_at'),
    )
```

### 步骤 5: 重复检测模块 (`duplicate_checker.py`)

**核心逻辑：**

```python
def check_duplicates(db, new_orders: list[dict]) -> list[dict]:
    """
    对每一条新记录，查询数据库中是否存在 name+address+phone 相同的记录
    返回: 重复记录列表 [{new_record, existing_record}, ...]
    """
    duplicates = []
    for new_order in new_orders:
        existing = db.query(Order).filter(
            Order.name == new_order["name"].strip(),
            Order.address == new_order["address"].strip(),
            Order.phone == new_order["phone"].strip(),
            Order.expire_at > datetime.utcnow()  # 只检查未过期记录
        ).first()
        if existing:
            duplicates.append({"new": new_order, "existing": existing})
    return duplicates
```

> **注意**: 比较前需对字符串做标准化处理：去除首尾空格、统一全角半角字符。

### 步骤 6: 定时清理模块 (`scheduler.py`)

```python
from apscheduler.schedulers.background import BackgroundScheduler

def cleanup_expired_orders():
    """每小时执行一次，删除 expire_at < now 的记录"""
    db = SessionLocal()
    try:
        db.query(Order).filter(Order.expire_at < datetime.utcnow()).delete()
        db.commit()
    finally:
        db.close()

scheduler = BackgroundScheduler()
scheduler.add_job(cleanup_expired_orders, 'interval', hours=1)
scheduler.start()
```

### 步骤 7: FastAPI 主入口 (`main.py`)

**API 路由设计：**

| 方法 | 路径 | 说明 |
|------|------|------|
| `POST` | `/api/upload` | 上传表格文件，解析+入库+重复检测 |
| `GET` | `/api/orders` | 分页查询订单列表 `?page=1&page_size=20&search=关键词` |
| `POST` | `/api/orders` | 手动新增单条记录 |
| `PUT` | `/api/orders/{id}` | 更新记录 |
| `DELETE` | `/api/orders/{id}` | 删除单条 |
| `POST` | `/api/orders/batch-delete` | 批量删除 `{ids: [1,2,3]}` |
| `GET` | `/api/orders/{id}` | 查询单条详情 |

**上传接口特殊处理：**

- 接收 `multipart/form-data` 文件
- 调用 `excel_parser` 解析
- 若列匹配失败，返回 `{status: "column_mismatch", headers: [...], matched: {...}}`
- 若列匹配成功，入库 + 调用 `check_duplicates`
- 返回 `{status: "ok", total: N, duplicates: [...], inserted: N}`

## 关键注意事项

1. **全角/半角统一**: 电话号码中的全角数字需转为半角后再比较
2. **字符串 trim**: 姓名、地址、电话入库前和比较前都要去除首尾空格
3. **大文件处理**: 超过 10,000 行时考虑分批入库 + 进度反馈
4. **并发安全**: SQLite 在写入时锁定，FastAPI 异步操作需注意 `check_same_thread=False`
5. **错误处理**: 所有 API 需返回统一格式 `{success: bool, data: any, message: string}`
